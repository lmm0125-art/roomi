# 수동 스모크 체크리스트 (v1.82)

자동 테스트(`npm test`)가 다루지 않는 화면 동작을 사람이 확인한다.
환경: 로컬 `ROOMI_TEST_NO_LLM=1 DB_PATH=/tmp/roomi-smoke.db node --experimental-sqlite server.js` (규칙 폴백, 키 불필요).
브라우저: `http://127.0.0.1:3000/?sharecode=…` 없이 열면 403 이 나올 수 있으니 실행 환경의 접속 방식에 맞춘다.
결과는 각 항목 앞의 `[ ]` 를 `[x]` 로 바꾸고, 실패하면 화면 문구와 함께 적는다.

## A. 보호자 게이트 (PIN)

- [ ] **A1 PIN 없는 계정 → 곱셈 문제**: 새 계정으로 보호자 게이트를 열면 «N × M = ?» 가 보이고 입력칸은 숫자 키패드다.
- [ ] **A2 정답 통과**: 정답을 넣으면 «부모 승인 완료!» 말풍선이 뜨고 플레이 타이머가 다시 돈다.
- [ ] **A3 PIN 설정**: 설정 화면에서 PIN 4자리(예: 1357)를 저장한다.
- [ ] **A4 PIN 계정 → PIN 입력**: 게이트를 다시 열면 «보호자 PIN 4자리를 입력해 주세요» 가 보이고, 입력칸은 가려진다(password).
- [ ] **A5 PIN 틀림**: 0000 을 넣으면 «PIN 이 틀렸어요» 가 뜨고 게이트는 열린 채로 남는다.
- [ ] **A6 PIN 정답**: 1357 을 넣으면 통과한다. 3자리·문자 입력은 «PIN 숫자 4자리를 입력해 주세요» 로 막힌다.
- [ ] **A7 하루 5회 잠금**: 틀린 PIN 을 5번 넣으면 다음 시도부터 «오늘은 시도가 너무 많아요» 가 뜬다(서버 카운터).

## B. 보호자 대시보드 블록

대시보드는 아이 계정으로 몇 번 가르친 뒤(설명 화면) 연다.

- [ ] **B1 가르친 것**: «이번 주 아이가 루미에게 가르친 것 (검증된 설명)» 블록에 맞게 가르친 개념이 보인다.
- [ ] **B2 미검증은 안 보임**: 틀린 설명(예: «분모가 클수록 더 큰 수야»)은 이 블록에 나타나지 않는다.
- [ ] **B3 등불 수**: «기억 등불 N개 · 수정 구슬 M개» 가 가르친 개념 수와 맞는다.
- [ ] **B4 편지 미리보기**: 흐려진 등불이 있으면 «루미의 편지 미리보기 (아직 보내지 않았어요)» 가 보이고, 발송 버튼은 없다. 본문에 대화 내용이 들어가지 않는다.
- [ ] **B5 이번 주 공부 일수**: 「이번 주」 줄의 «N일 공부» 가 버튼을 안 눌러도 설명·학습 대화를 한 날을 센다.
- [ ] **B6 개인정보**: 블록 어디에도 아이 메시지 원문·이메일 전체가 나오지 않는다(이메일은 마스킹).

## C. 설명(teach-back) 화면 — 채점하지 않는다

- [ ] **C1 맞는 설명**: 「분모가 같으면 분자끼리 더하면 돼요」 → 칭찬·점수·정답 표시 없이 «…라고 설명했구나. 만약 …?» 형태의 답이 온다.
- [ ] **C2 틀린 설명**: 「분모가 클수록 더 큰 수야」 → 화면은 똑같이 부드럽다(맞다/틀리다 표시·빨간 표시 없음). 질문이 빈틈을 겨냥한다.
- [ ] **C3 등불 이름**: 설명을 마친 뒤 기억 등불 목록에 개념명이 보인다(«방금 배운 것» 이 아니다).
- [ ] **C4 하루 한도**: 설명을 5번 넘게 하면 «오늘은 설명을 충분히 했어!» 가 뜬다.

## D. 학습 대화 (규칙 확인)

- [ ] **D1 질문형은 확인이 아님**: 「1/2+1/3=2/5 이거 맞아?」 뒤에도 단계가 «확인(confirm)» 으로 넘어가지 않는다.
- [ ] **D2 부정형은 확인이 아님**: 「못 풀었어」 도 같다.
- [ ] **D3 L1 회전**: 「모르겠어」 를 연속으로 쳐도 같은 한 문장이 반복되지 않는다(세 가지 되묻기 중 하나).
- [ ] **D4 학습 한도**: 모델을 부른 학습 턴 10개 뒤 11번째는 «오늘은 여기까지!» 이고, 「스스로 해결」 버튼은 한도에 안 든다.
