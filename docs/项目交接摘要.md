## 0. 工作空间范围与一句话定位

**工作空间实际只有 1 个独立项目**：`dorobot/`（RooMi）。另有 2 个辅助目录：`output/`（docx 交付产物）、`ref/`（官方头像素材）；`.slidep/`、`.workbuddy/`、`.genie` 为工具/部署元数据。

**一句话定位**：**RooMi(루미 = Room+Me)** — 让孩子亲手涂色的机器人住进个人房间(마이룸)，用「6 处常规获取 / 4 处消耗」的 셀 经济 + 每日 AI 课题 + 7 日连续奖励，为「没课的日子」设计再次登录理由的**独立内容模块**（汉阳 ERICA AI학과 IC-PBL 4조 DOROLINK；原企业课题 ㈜도로 DOROBUS，现按自有产品推进）。

## 2. 已定稿核心决策

| 项目 | 结论（依据） |
|---|---|
| **问题定义** | “수업 없는 날, 접속할 이유가 없다”（外部反馈）+ 셀 获取渠道偏少 + 成长不可见（原稿 p.2） |
| **策略** | 扩大 셀 生产处（每日 3 种非上课获取）→ 以收集/成长动机每日回归（执行方案 §3 步骤2） |
| **循环** | `접속→사용→보상→재접속`：마이룸 进入记 1 次 + 奖励防重复（UNIQUE；V8/V14 ✅） |
| **셀 结构** | **常规 6 获取**：가입100 / 로봇완성50 / 과제30+ / 게임10~110 / 연속10~100(+28일200) / 출석100；**代码另有第 7 条**：mailbox（运营发放）。**4 消耗**：부품/장식/스킨/조각교환（CODEX 另计 display 为第 5 类） |
| **DB** | **15 테이블**·users 为中心 star schema；实线=1:N、虚线=N:1；UNIQUE 8 类（含 `users.nickname` 则 9） |
| **指标** | 재접속률=활동일수÷경과일수（每日=100%）· 体류 40 分上限 · 셀 사용량 · 과제 제출률 — SQL 聚合、每周自动（V8 最终） |
| **说明口径** | 独立原型 · 登录流程可省略 · SQLite 仅原型 · 不做企业素材/GLB |
