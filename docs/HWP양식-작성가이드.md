## 4. 주의사항

1. **양식은 반드시 HWP 로 제출** — 현재 `과제수행계획서` 는 md/docx 로만 존재합니다.
   교수가 HWP 양식을 배포했다면 **그 양식에 맞춰 제출**해야 합니다.
2. **팀코드는 모든 양식에 동일하게** 기재합니다.
3. **팀활동보고서는 매주** — 몰아서 쓰면 신뢰도가 떨어집니다. 지금부터라도 주 1회.
4. 파일명은 양식 그대로 두고, 내용만 채우는 것을 권장합니다.
