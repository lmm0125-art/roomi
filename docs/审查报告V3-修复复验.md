## 二、🟡 本次修复新引入的问题（1 项）

### 조각 교환 후 `have` 가 1 로 잘못 표시된다（오프바이원）

`/api/robots/me` 的统计式为 `(o.qty||1)`——**`qty` 为 0 时被 `||` 替换成 1**：

```js
// server.js:711-717
const shards = owned.filter(o=>o.type==='shard').map(o=>o.name);          // qty=0 인 행도 포함
const shardQty = owned.filter(o=>o.type==='shard').reduce((a,o)=>a+(o.qty||1), 0);   // 0 → 1
...
qty: Object.fromEntries(owned.map(o=>[o.name, o.qty||1])),                // 0 → 1
```

**实测（干净账号，恰好买 3 个）**：
```
구매 직후 DB        : [{"name":"부품 조각","qty":3}]
robots/me           : shardProgress={"have":3,"need":3}  shards=["부품 조각"]
POST /api/shop/exchange → {"ok":true,"part":"나사 장식","remaining":0}
교환 후 DB          : [{"name":"부품 조각","qty":0},{"name":"나사 장식","qty":1}]   ← qty=0 행이 남음
교환 후 robots/me   : shardProgress={"have":1,"need":3}  shards=["부품 조각"]        ← 실제 0개인데 1로 표시
```

**影响**：交换成功的那一刻（孩子最专注的时候），库存显示"조각 1/3"并继续列出"부품 조각"。孩子以为自己还有 1 个，再买 2 个却发现还是换不了（只有 2 个）→ 困惑。这正是本次新做的功能，属于**已交付但数字不对**。

**最小修复（3 行）**：
```js
const owned = db.prepare(`SELECT i.name,i.type,v.qty FROM inventory v
  JOIN items i ON i.id=v.item_id WHERE v.user_id=? AND v.qty>0`).all(u.id);   // 过滤 qty>0
const shardQty = owned.filter(o=>o.type==='shard').reduce((a,o)=>a+o.qty, 0); // 去掉 ||1
qty: Object.fromEntries(owned.map(o=>[o.name, o.qty])),
```
（或在 `exchange` 里当 `qty` 归零时直接 `DELETE` 该行，一并解决"残留 0 行"。）
