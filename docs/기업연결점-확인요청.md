## 2. 기존 자산과의 연결점 (확인 부탁드리는 부분)

> "구현 가능성 = 기존 셀·상점·마이룸과의 연결점이 명확한가" 라고 하셔서, 표로 정리했습니다.

| 기존 자산 | 저희가 추가하는 것 | 방식 | 확인 필요 |
|---|---|---|---|
| **셀(재화)** | 획득처 **5개 추가** — 로봇 완성 · AI 과제(매일) · 미니게임 2종 · 연속 방문 | 서버 지급 로직 | 지급량이 기존 경제와 맞는지 |
| | 소비처 **2종 추가** — 색칠 스킨(반복 구매) · 부품 조각(재료) | 상점 아이템 | 가격대가 적절한지 |
| **상점** | 아이템 추가 (부품 3종 · 장식 2종 · 스킨 6종) | `items` 테이블에 행 추가 | **기존 상점에 그대로 얹어도 되는지** |
| **마이룸** | 로봇 1기가 **상주**하고 걸어다님 / 부품·장식을 3D 오브젝트로 배치 | Babylon.js 7 | **기존 마이룸에 오브젝트를 추가하는 방식이 맞는지** |
| **공작소** | 위 콘텐츠를 **모듈 단위**로 호출 | 진입점 연결 | **어떤 형태로 넘겨드리면 되는지** |
| **수업(DLS)** | 이번 주 주제를 받아 **AI 과제 질문 생성** | 주제 입력(관리자 API) | 수업 주제를 어떻게 전달받으면 되는지 |

### 특히 확인받고 싶은 3가지
1. **공작소에 어떤 형태로 넘기면 되나요?** (독립 웹 모듈 / iframe / API / 소스 이관)
2. **기존 마이룸에 저희 로봇을 넣는 방식**이 맞나요? 아니면 별도 공간이 나은가요?
3. **저희가 추가하는 셀 획득처 5개**가 기존 설계와 충돌하지 않나요?

## 3. 재화(셀) 흐름

```
[획득] 가입100 · 로봇완성50 · AI과제30(매일) · 간식/칭찬10×2(매일)
       · 미니게임 10~50 / 50~110 · 연속방문 10~100(7일 주기) · 부품보너스 +2/개
                    ↓
              셀 지갑 (모든 거래 기록)
                    ↓
[소비] 부품 60~120 · 장식 40~100 · 스킨 30~60(반복) · 조각 20(반복)
                    ↓
        로봇·마이룸 꾸미기 → 자랑하기 → 다시 접속
```

**설계 의도**: "수업이 있는 날만 셀을 얻는다" → **"매일 5가지 방법으로 얻는다"**
