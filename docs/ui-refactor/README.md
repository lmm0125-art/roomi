## 2차 구현 (2026-10-28)

- **30분 예고** 토스트 → 40분 잠금 (한 세션 1회)
- **퍼즐 연습 모드**: 1일 3문제와 별도로 5문제(보상 없음)
- **주간 추천/주간 랭킹**: 요일별 추천 게임, 최근 7일 게임별 top5
- **상점 분류 필터**: 전체/부품/장식/스킨/조각
- **음성**: 채팅 🎤 입력(Web Speech API) + 답변별 🔊 읽어주기 + 자동 읽기 설정
- **책장**: 해결한 문제 수만큼 방 안 책 시각화
- **보호자 대시보드**: 오늘 플레이/한도, 이해도, 스스로 해결, 대화 수, 게임 최고점, 7일 접속
- **접근성**: 글자 크게, 색약 모드(+/- 기호), 키보드 포커스 링

## AI 주도 학습 계획 (2026-10-28)

- 마이룸에 «오늘의 학습 계획» 카드: AI가 3단계(개념→퍼즐→복습/게임) 생성
