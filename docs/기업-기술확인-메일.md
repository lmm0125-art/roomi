| 레이어 | 현재 | 비고 |
|---|---|---|
| 3D | **Babylon.js 7** | 마이룸·로봇·공작소 |
| 서버 | **Node 22 + Express 5** | REST 38개 |
| DB | node:sqlite (내장) | 15 테이블 · UNIQUE 8종 |
| 인증 | 자체 토큰 | 관리자 키 별도 |
| 프런트 | 순수 HTML/CSS/JS | 프레임워크 없음 |

**확인 부탁드리는 5개 항목**

| # | 항목 | 여쭙는 이유 |
|---|---|---|
| 1 | 마이룸 **3D 엔진·버전** | Babylon 7 문법을 그대로 쓸 수 있는지 (버전 차이가 크면 씬을 다시 만들어야 합니다) |
| 2 | **프런트 프레임워크** | 저희 화면을 컴포넌트로 옮겨야 하는지, 아니면 모듈로 임베드하면 되는지 |
| 3 | **로그인 방식** (SSO/JWT/세션) | 학생 계정이 이미 있으니 자체 가입은 끄고 연동만 하려 합니다 |
| 4 | **DB 종류** (MySQL/PostgreSQL) | 스키마는 표준 SQL이라 DDL만 바꾸면 됩니다. UNIQUE 8종은 그대로 유지할 예정입니다 |
| 5 | **배포 형태** (컨테이너/CDN) | 정적 자산과 Node 서비스를 어디에 올리면 되는지 |

> 다섯 항목 중 1·2번만 정해져도 **3일 안에 임베드 시연**이 가능하고,
> 3·4번까지 정해지면 **계정 연동과 데이터 이전**까지 2주 안에 됩니다.
