## 1. 효과음 — 소리가 전혀 없던 문제

**WebAudio 오실레이터로 직접 만든다. 오디오 파일 0개, 다운로드 0바이트.**
(앞서 기억게임 기호를 유니코드로 해결한 것과 같은 방식 — 에셋을 받지 않는다.)

| 소리 | 언제 | 구성 |
|---|---|---|
| click | 모든 버튼·팔레트·게임칸 (전역 캡처 리스너 1곳) | 620Hz 사각파 60ms |
| coin | **셀이 늘어난 순간** | 880→1320Hz |
| levelup | 레벨 업 | 660→880→1175Hz 3음 |
| wrong | 기억게임 오답 / 반사게임 실수 | 300→220Hz |

**보상음은 `setBalance()` 한 지점에 걸었다** — 값이 *증가*할 때만 울린다. 과제·미니게임·구매 등 모든 보상 경로를 한 곳에서 잡으므로 빠뜨릴 수 없고, 로딩·화면 전환에서는 울리지 않는다.

상단바에 **🔊/🔇 토글**을 추가하고 `localStorage` 에 저장한다(교실·도서관 배려).
> ⚠ 브라우저 정책상 오디오는 **첫 클릭 이후**부터 열린다. 온보딩 "시작하기" 클릭이 그 역할을 겸한다.

## 2. 자랑하기 — 자체 셀 흐름도의 '전시·자랑' 단계

자체 `2-셀흐름도.svg` 에 **「전시·자랑」을 그려 놓고 구현이 없었다.** 랭킹·방문·공유 전부 0건이었다.

**「📸 내 로봇 자랑하기」 버튼** → 3D 화면을 PNG 로 담아 모달로 보여주고 저장까지.
```js
bjs.scene.render();                    // 방금 그린 프레임 보장
const url = cv.toDataURL('image/png'); // preserveDrawingBuffer:true 라 가능
```
**서버가 필요 없다.** 아이가 부모님·친구에게 보여줄 수 있는 최소 형태다.

## 3. 오늘의 랭킹 — '1등'이라는 목표

`GET /api/rank/daily` — 오늘 기록만, 두 게임 각 top 5.
- **반사속도는 낮을수록**, **기억순서는 높을수록** 좋다 → 정렬 방향이 반대인 것을 서버가 처리(`better:'low' / 'high'`)
- 내 기록과 내 순위를 함께 반환 → `나` 로 표시(마스킹 없음)
- **개인정보 보호**: 다른 아이 닉네임은 첫 글자만 남긴다 (`민준이` → `민○○`)
- 데모·시연·테스트 계정 제외

실측:
```
반사속도(ms 오름차순):  1.민○○(320)  2.서○(410)  3.지○○(500)
기억순서(단계 내림차순): 1.서○(8)    2.민○○(5)   3.지○○(3)
```

> 닉네임 마스킹은 **평가기준 「安全·个人信息」에 대한 의도적 대응**이다. 발표에서 "아이들끼리 순위를 보되 서로를 특정할 수 없게 가렸다"고 설명할 수 있다.

## 4. 저사양 기기 자동 조정

`adaptToDeviceRatio` + 메시 71개 + 1024 그림자 + 후처리인데 **FPS 감시도 폴백도 없었다.** 학교 태블릿·크롬북에서 버벅일 위험.

시작 후 **2.5초간 실제 FPS 를 재서** 28 미만이면 단계적으로 포기한다:
```js
engine.setHardwareScalingLevel(1.6);   // 해상도 ↓
scene.__shadow.dispose();               // 그림자 끔
bjs.pipeline.dispose();                 // FXAA·비네트 끔
scene.particleSystems → dispose()       // 먼지 끔
```
**아이는 버벅임을 화질보다 훨씬 크게 느낀다** → 부드러움을 우선한다. 판정 결과는 `bjs.fps` / `bjs.lowPerf` 로 남는다.

## 6. 주말 한정 아이템 — "주말에 다시 오자"

`items` 에 `limited_days` 컬럼 추가(`'0,6'` = 일·토). **2종 시드**:
- **보라 포커 스킨** 45셀 — `SKIN_PALETTES` 에 이미 정의돼 있어 그대로 사용
- **무지개 스킨** 60셀

**핵심 설계: 숨기지 않고 보여준다.**
```
🔒 주말 한정          ← 배지
토·일요일에만 살 수 있어요   ← 안내
[주말 한정]           ← 비활성 버튼
```
숨기면 예고가 사라진다. **"지금은 못 사지만 주말에 열린다"가 재방문 이유**다.
`/api/shop/buy` 에서 **서버도 차단**하므로 프론트를 우회할 수 없다(실측: 평일 구매 시도 → `HTTP 400`).

> 스킨으로만 구성한 이유: 색이 실제로 바뀌므로 **"사도 안 보이는" 함정이 될 수 없다.** (P0-1·V2 에서 한 번 겪은 문제를 반복하지 않는다.)
