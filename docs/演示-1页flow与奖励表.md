# 演示用 1 页 flow + 奖励表（2026-10-27）

> 用途：对外演示/评审时的一页说明；**不包含录屏**（demo 录屏按用户要求另行处理）。

## 1. 四幕 flow（90 秒）

```
① 卡住            ② 求助                    ③ 自解                     ④ 陪伴
┌──────────┐   ┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│ 방이 어둡다 │ → │ 루미에게 질문      │ → │ L1 되묻기          │ → │ 아이가 직접 고침    │
│ 문제를 못 풂 │   │ (같이 공부 모드)   │   │ L2 비유            │   │ 방이 밝아짐         │
│            │   │                  │   │ L3 다음 한 단계     │   │ 책장 +1, 로봇 성장  │
└──────────┘   └──────────────────┘   └──────────────────┘   └──────────────────┘
                                                                    ↓
                                                          셀 +5 / 이해도 +3
                                                                    ↓
                                                          상점에서 학습角 구매
                                                                    ↓
                                                          다음 날 다시 질문
```

**一句话**：`卡住 → 提问 → 提示 → 自己解决 → 房间变亮 → 明天再来`。

## 2. 3 个演示场景

| # | 场景 | 用户说 | 루미 回（要点） | 结束状态 |
|---|---|---|---|---|
| 1 | 코딩 막힘 | “반복문이 안 돼요” | L1 “몇 번 반복하려고 했어?” → L2 “반복문=같은 일 여러 번” → L3 “3번부터 써 보자” | 孩子改对 → 房间亮、书 +1 |
| 2 | 개념 질문 | “변수가 뭐예요?” | 类比“이름표 붙은 상자” + 例子 + 检查问题 | 理解度 +3 |
| 3 | 수다/감정 | “오늘 시험 망쳤어” | 共情 2 句 + “지금 기분이 어때?” + 休息建议 | 不诊断、不给分 |

## 3. 奖励表（셀）

| 来源 | 条件 | 奖励 | 频率 |
|---|---|---|---|
| 버그 슈터 | 分数 50 / 500 / 1000 / 1800 / 3000 / 5000 | 10 / 20 / 30 / 50 / 80 / 110 | 每日 1 次计奖 |
| 오늘의 퍼즐 | 答对 4 选 1 | +30 | 每日 1 次 |
| 일일 과제 | feed / praise / AI 미션 | 30 起（部件加成 +2/个，上限 +10） | 每日 |
| 연속 방문 | 1–7 日 | 10 / 15 / 25 / 35 / 50 / 60 / 100（28 日 +200） | 每日 |
| 수업 출석 | 出勤码 `1004` | +100 | 每周 1 次 |
| 学习自解 | “내가 해봤어요” | +5셀 + 理解度 +3 | 每日 3 次 |

**消耗**：부품（60/80/120）· 장식（40/100）· 스킨（30/45/60）· 조각 교환（3→1）· 학습角（功能化）。

## 4. 界面入口（演示路径）

1. 开始 → 「데모 계정으로 바로 보기」
2. 마이룸 → 右下 💬 → 「같이 공부」→ 提问
3. 看 L1/L2/L3 → 点「내가 해봤어요」→ 房间灯变亮
4. 미니게임 → 「버그 슈터」60 秒 → 结算 +셀
5. 미니게임 → 「오늘의 퍼즐」→ 3 hints → 答对 +30
6. 상점 → 买学习角 → 回到마이룸看 HUD（Lv / 🔥 / 📚）
