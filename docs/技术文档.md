## 2. 运行与部署

### 2.1 环境要求

- Node **>= 22**（`node:sqlite` 内置，必须加 `--experimental-sqlite`）
- 依赖只有 `express ^5.2.1`
- 3D 用 Babylon.js 7（CDN，失败自动降级 2D SVG）

### 2.2 本地运行

```bash
npm install
node --experimental-sqlite server.js     # http://localhost:3000
# macOS 双击：./start.command
```

### 2.3 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3000` | HTTP 端口 |
| `DB_PATH` | `./roomi.db` | SQLite 路径；部署必须持久化 |
| `ADMIN_KEY` | `''` | 未设置时所有 `/api/admin/*` 返回 **503**（fail-closed） |
| `CLASS_CODE` | `1004` | 课堂出勤码（全局，非按班级） |
| `DEEPSEEK_API_KEY` | 文件 `deepseek_key.txt` | **唯一 LLM**（DeepSeek） |
| `LLM_MODEL` | `deepseek-chat` | 非 reasoner（**不启用深度思考**） |
| `LLM_TIMEOUT_MS` | `6000` | 单次请求超时 |
| `LLM_MAX_TOKENS` | `220` | 输出上限 |

### 2.4 部署

```bash
DB_PATH=/tmp/dorobot-online.db \
CLASS_CODE=1004 \
ADMIN_KEY=<rotate-me> \
node --experimental-sqlite server.js
```

> ⚠️ `/tmp` 在重新部署时会被清空；生产需挂持久目录。  
> ⚠️ `CODEX_CONTEXT.md` 写的是 `/tmp/roomi-online.db`，与实际 startCmd `/tmp/dorobot-online.db` 不一致，**部署前需确认一个为准**。

## 4. 架构

```
Browser (vanilla JS, 1280×720 基准)
  │ fetch JSON; header X-Token (session) / X-Admin-Key (admin)
  ▼
Express 5 (server.js)
  ├─ static: public/
  ├─ auth: users.token（不透明 token，注册时生成；无密码）
  ├─ domain: users / robots / quests / economy / growth / mailbox / class / workshop / games
  ├─ LLM: prompt → isSafeText/sanitizeLine → Gemini 链 → DeepSeek → preset
  └─ SQLite (node:sqlite, DatabaseSync)
```

- **无** Redis/缓存/队列/WebSocket；所有状态在单个 SQLite 文件。
- **3D**：Babylon.js 7 程序化 메시；CDN 失败 → 2D SVG 降级。
- **鉴权**：`POST /api/user {nickname}` → `{user:{id, token}}`；前端存 `localStorage`，每次带 `X-Token`。

## 7. 业务规则与常量

### 7.1 셀 获取 / 消耗

| 获取源 | 金额 | 频率 |
|---|---|---|
| 가입 (welcome) | +100 | 1 次 |
| 로봇 완성 (robot_create) | +50 | 1 次 |
| 일일 과제 (daily_quest) | +30 起（+部件加成） | 每日 |
| 미니게임 (game) | 10–110 | 每日各 1 次 |
| 연속 방문 (streak) | 10–100（28 日 +200） | 每日 |
| 수업 출석 (class_attend) | +100 | 周 1 次 |
| 우편함 (mailbox) | 运营发放 | 不定 |

> 答辩口径“6 获取 / 4 消耗”；代码另有 mailbox（第 7 获取）与 display（第 5 消耗）。

### 7.2 成长

- `growthStage`: Lv1–3 婴儿 / Lv4–7 青少年 / Lv8+ 成体
- 经验来源：课题、游戏、互动等（`addExp`）
- 3D 外形按 stage 改变（身高约 2.65→3.58）
- **`understanding`（2026-10-27）**：学习模式“내가 해봤어요”+3；每日最多 3 次；+5셀
- **房间状态**：`lit = min(1, understanding/30)`；`books = min(12, solved)`
- **AI 계획**：하루 3단계, `learning_plans`에 캐시; 3단계 완료 +10셀(1/일)
