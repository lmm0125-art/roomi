## 二. 독자적으로 개발한 4가지 포인트

### ① 색칠 → AI 성격 변환 (핵심)
- **기존**: 꾸미기는 "외관만" 바꾼다. 외형과 캐릭터성은 분리되어 있다.
- **루미**: 칠한 색 조합이 **성격(반짝이/느긋이 등)과 인사말을 결정**한다. "다른 색을 칠하면 다른 성격이 나온다"는 **호기심 기반 반복 플레이**가 생긴다.
- **구현**: `COLOR_PERSONA` 결정론 매핑 + LLM 대사 다듬기 + 안전 필터. LLM 실패 시 규칙 엔진 폴백(무중단).

### ② 수령형 우편함 — 보상을 "여는 행위"로
- **기존**: 보상은 즉시 지급되어 알림만 뜬다. 우편함을 열 이유가 없다.
- **루미**: 보상은 **우편함에 쌓이고 아이가 직접 받아야** 잔액에 들어간다. → **우편함 탭 자체가 재방문 이유**가 된다.
- **부가 효과**: 운영자가 공지·보상을 **일괄 발송**할 수 있어(평가 ①-③ "운영자가 콘텐츠 추가·수정") DOROBUS 우편함과 자연스럽게 연결된다.

### ③ 수업 ↔ 콘텐츠 연결 (회사 기대효과 ② 직격)
- **기존 DOROBUS**: 셀 획득처가 "수업·과제·타자 1등" 에 한정 → 수업 없는 날 접속 이유가 없었다.
- **루미**: 선생님이 알려준 **4자리 코드로 수업 출석 → +100셀**(하루 과제 +30 보다 큼).
  + **이번 주 수업 주제가 AI 과제 문제로 그대로 들어간다**(도로랜드 챕터 자동 순환).
- → "수업도 하나의 콘텐츠" 라는 회사의 요구를 **셀 금액 + 문제 출제 두 축**으로 구현.

### ④ 경제가 안전한 순환 구조
- 셀 획득처 6곳 / 소비처 5곳 + **부품 1개당 과제 보상 +2셀**(최대 +10) → 부품을 살 이유가 숫자로 남는다.
- 조각 교환은 **정가 비례**(회수율 100%) → 상점 가격표가 유지된다(초기 버그 수정).
