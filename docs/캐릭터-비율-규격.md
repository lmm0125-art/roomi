# 캐릭터 비율 규격 — 루미 4종

> 새 템플릿을 추가할 때 이 표를 먼저 채우고, 아래 비율을 만족하는지 확인한다.
> 목적: 템플릿마다 따로 놀던 치수를 **하나의 기준(W·H)** 에 묶어, 다섯 번째 템플릿이 생겨도 어긋나지 않게 한다.

---

## 1. 기준값

| 기호 | 정의 |
|---|---|
| **W** | 몸통 가로 폭 (실루엣 기준, 스케일 반영 후) |
| **H** | 몸통 세로 높이 |

모든 비율은 W·H 대비로만 표기한다. 절대 좌표(y 등)는 템플릿마다 다를 수 있다.

---

## 2. 비율 규칙

| 항목 | 규칙 | 이유 |
|---|---|---|
| **머리 폭** | `1.05 ~ 1.15 W` | 이보다 작으면 어른 비율, 크면 유아 비율로 보인다 |
| **팔 길이** | `0.45 ~ 0.55 H` | 짧으면 장난감, 길면 원숭이 |
| **팔 뿌리 x** | `0.50 ~ 0.60 W` (반폭 기준) | **몸 표면 안쪽에 묻혀야** '붙인 부품'이 아니라 '자란 팔'로 읽힌다 |
| **팔 뿌리 y** | 몸 중심 + `0.05 ~ 0.30 H` | 어깨가 너무 높으면 목에 붙는다 |
| **발 폭** | `0.28 ~ 0.34 W` | 이보다 크면 신발만 보인다 |
| **목 지름** | `0.32 ~ 0.45 W` | 머리와 몸 사이가 끊겨 보이지 않을 만큼 |

---

## 3. 현재 값 (2026-10-24 기준)

| | doro | roundy | boxy | tally |
|---|---|---|---|---|
| W (몸 폭) | 1.00 | 1.21 | 0.95 | 0.90 |
| H (몸 높이) | 1.20 | 1.04 | 1.25 | 1.35 |
| 머리 폭 | 1.08 | 1.20 | 1.10 | 1.15 |
| **머리/W** | 1.08 | 0.99 | 1.16 | **1.28** ⚠ |
| 팔 길이 | 0.55 | 0.55 | 0.66 | 0.72 |
| **팔/H** | 0.46 | 0.53 | 0.53 | 0.53 |
| 팔 뿌리 x | 0.50 | 0.62 | 0.52 | 0.50 |
| **x/W (반폭)** | 0.50 | 0.51 | 0.55 | 0.56 |
| 발 폭 | 0.32 | 0.30 | 0.36 | 0.24 |
| **발/W** | 0.32 | 0.25 | 0.38 ⚠ | 0.27 |

⚠ 표시는 규칙을 살짝 벗어난 값 — 의도적(머리가 큰 캐릭터성)이거나 다음 조정 대상.

- **tally 머리 1.28W**: 이 캐릭터는 '머리 작고 몸 긴' 컨셉이라 의도적으로 유지.
- **boxy 발 0.38W**: 각진 발이 특징이라 유지. 대신 각을 살리려고 폭을 키웠다.

---

## 4. 새 템플릿 추가 체크리스트

1. `buildRobotModel` 의 헤드/바디 분기에 형상을 추가하고 `bodyRx / bodyRy / bodyCy` 를 채운다 (부품 부착 기준).
2. `P` 표에 `neck · hand · foot · ear · rim` 을 추가한다 (없으면 `null`).
3. 위 §2 비율을 만족하는지 계산한다 — 특히 **팔 뿌리 x ≤ 0.60W**.
4. 디버그 훅으로 4종과 함께 렌더해 눈으로 비교한다:
   ```js
   window.__buildRobotModel(scene, root, palette, 'newTemplate', null, null, 2)
   ```
5. `slides`/2D SVG(`buildBotSVG`)도 같은 비율로 그려야 2D·3D가 어긋나지 않는다.
