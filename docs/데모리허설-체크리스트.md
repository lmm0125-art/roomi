## 一. 발표 당일 시나리오 (약 3분)

**준비**: 발표 전날 밤 데모 계정으로 1회 접속 → 스트릭이 "며칠째" 로 보이는지 미리 확인.
**당일 순서**:

1. **시작 화면** (10초)
   - "닉네임만 입력하면 로그인 과정 없이 시작합니다" → **데모 버튼 클릭**
   - 포인트: *신규 계정은 지표가 0이라, 7일치 성장 데이터를 넣은 데모 계정으로 보여드리겠습니다*
2. **마이룸** (60초) — 스크린샷 대신 라이브
   - 3D 방 + 내가 칠한 색 로봇 (마우스로 한 번 돌려 보인다)
   - 말풍선: AI가 만든 인사말 ("안녕! 나 루미야…")
   - 배지 줌: **Lv.5 청소년 / 🔥6일 연속 / 과제 +6셀** → *"매일 돌아올 이유를 눈에 보이게 만들었습니다"*
   - **CH·2 멈춘 기계의 노래** 배지 → *"AI 과제를 이번 주 수업 주제와 연결했습니다"*
3. **오늘의 과제** (40초)
   - 4단계 진행 (간식→칭찬→AI과제→미니게임) 중 하나 클릭 → 보상 즉시 반영
   - AI 과제 카드: 주제 태그 + 질문 → 답 제출 → +30셀
4. **미니게임** (30초)
   - 기억 순서 1~2판: *"색+모양 이중 단서로 색각 이상 아이도 플레이 가능합니다"*
   - (시간 없으면 생략 가능 — 스크린샷으로 대체)
5. **공작소** (40초) ★신규 — 공작소 탭 → 색칠 다시 하기 → AI 성격 재생성 → "로봇에게 물어보기"에 주제 질문
   - 포인트: *"회사가 가장 원한 '공작소 안의 AI 모듈' 형태로 넣었습니다"*
6. **우편함** (20초) ★신규 — 선물 한 번에 받기 → 잔액 증가 확인
7. **수업 출석** (20초) ★신규 — 마이룸 카드에 선생님 코드 입력 → +100셀
   - 포인트: *"기대효과 ②'수업도 콘텐츠'를 셀 획득 경로로 구현했습니다"*
8. **상점** (30초)
   - 부품 구매 → 로봇에 즉시 반영 (로켓 부스터 추천 — 시각 효과最 큼)
   - 부품 조각: *"조각 수집 → 부품 교환, 가격 비례라 상점 경제가 유지됩니다"*
9. **리포트** (30초)
   - 재접속률 · 체류시간 · 7일 추이 그래프 · 셀 흐름
   - *"이 지표가 W13 효과 검증의 측정 도구입니다"*


> ⏱ **총 소요**: 전체 9단계 = 약 4분 40초. **3분 제한이면 4)미니게임(30초)을 건너뛰고** 스크린샷으로 대체하세요.
> 공작소·우편함·수업출석은 중간발표 요건(기획/DB설계/데모)에서 새로 보여줄 항목이라 **우선 유지**합니다.

**마무리 멘트**: *"코드는 기말 분량을 먼저 끝냈고, 남은 기간은 실제 사용자 5~10명 테스트와
DOROBUS 연결점 확정에 집중하겠습니다."*

## 二. 실패 대비 (Fallback)

| 상황 | 대응 |
|---|---|
| **인터넷 끊김 / 3D 안 뜸** | 2D SVG 로 자동 강등됨 → *"백업 모드입니다"* 하고 진행. 스크린샷 백업: `docs/` 의 r2-myroom 등 |
| **데모 버튼 오류** | 일반 닉네임(아무거나) 입력 → 시작 → 로봇 만들기 1분 시연으로 전환 |
| **AI 과제 로딩 지연** | LLM 490회/일 한도 + 폴백 대사 있음. 최악은 프리셋 문제 출제 |
| **프로젝터 해상도** | 노트북 1280×720 기준 제작. 발표 전 현장에서 1회 접속 확인 |
| **로컬 백업** | `cd dorobot && DB_PATH=/tmp/demo.db PORT=3000 node --experimental-sqlite server.js` → localhost:3000 (오프라인 완결) |

**발표 전날 체크 (전부 5분)**
- [ ] 라이브 접속 → 데모 계정 → 각 화면 1회씩 캡처 (오늘 데이터 기준이라 매일 다름)
- [ ] 주말이면 주말 한정 배너 확인 / 아니면 "주말 한정 이벤트도 있습니다" 멘트만
- [ ] 로컬 서버 기동 테스트 1회 (오프라인 백업 확보)
