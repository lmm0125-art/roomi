## 二、AI 과제 ↔ 이번 주 주제 연결

### 왜 필요했나
V2 검토에서 지적한 항목입니다.
> 현재 질문은 "오늘 가장 재미있었던 일은?" 같은 **일반 일상 질문**이다. DLS 수업 내용이나 도로랜드 챕터가 어디에도 들어가지 않는다.
> 평가기준 ③은 **「세계관/수업과 연결」**을 명시적으로 요구한다.

즉 "로봇이 매일 질문한다"까지만 있고 **교육과의 연결고리가 없었습니다.**

### 구조
```
weekly_topics (운영자가 주차별로 지정)  ──┐
                                          ├─→ currentTopic() ─→ LLM 프롬프트
DEFAULT_TOPICS (도로랜드 챕터 자동 순환) ──┘                  └─→ 예비 질문 세트
                                                              └─→ daily_quests.topic 기록
                                                              └─→ /api/growth/me → 화면 배너
```

**기본 주제 = 도로랜드 챕터** (지정이 없으면 주차에 따라 자동 순환)
| CH | 주제 | 키워드 |
|---|---|---|
| 1 | 도로랜드 신입 사원 | 첫 출근, 새 친구, 설렘 |
| 2 | 멈춘 기계의 노래 | 고장, 원인 찾기, 고치기 |
| 3 | 별빛 저장고 | 모으기, 나누기, 약속 |
| 4 | 코딩 숲의 지도 | 순서, 규칙, 길 찾기 |
| 5 | AI 마을의 질문 | 질문하기, 배우기, 도와주기 |

### 달라진 질문 (실측, CH.2 주간)
```
주제: "멈춘 기계의 노래" (고장, 원인 찾기, 고치기)

· 무언가 고장 났을 때 어떻게 했니?          [주제: 멈춘 기계의 노래]
· 오늘 어려운 문제를 어떻게 해결했어?        [주제: 멈춘 기계의 노래]
· 다시 도전해 보고 싶은 일이 있니?          [주제: 멈춘 기계의 노래]
```
**LLM 이 실패해도 주제가 유지된다** — 예비 질문(`TOPIC_PRESETS`)도 챕터별로 준비했습니다. 예전 예비 질문은 주제와 무관한 일상 질문이라 실패 시 연결이 끊겼습니다.

### 운영자가 주제를 바꿀 수 있다 — 평가기준 ①의 실제 증거
```bash
curl -X POST -H "X-Admin-Key: <키>" -H "Content-Type: application/json" \
     -d '{"topic":"우리 동네 AI","keywords":"생활, 도움","chapter":3}' \
     http://localhost:3000/api/admin/topic
```
실측:
```
무키      → 401 {"error":"관리자 키가 필요해요"}
정답키    → 200 {"ok":true,"week":"2026-10-05","chapter":3,"topic":"우리 동네 AI",...}
이후 growth/me → source:"operator", topic:"우리 동네 AI"   ← 즉시 반영
다음 주(10-12) → 지정 없음 → 자동 순환 경로
```
> **"운영자가 문제·보상·내용을 추가/수정할 수 있는가"** 라는 평가기준에 대해, 지금까지는 `items`/`daily_quests` 테이블이 데이터 기반이라는 **구조적 주장**만 있었습니다. 이제 **교사가 이번 주 주제를 넣는 실제 동작**이 생겼습니다.

### 화면 표시
마이룸 사이드바, 「오늘의 과제」 위에 배너:
```
┌──────────────────────────────┐
│ CH.2   멈춘 기계의 노래        │   ← title 속성에 키워드
└──────────────────────────────┘
```
그리고 AI 과제 카드 안에도 `📚 이번 주 주제 · 멈춘 기계의 노래` 칩을 붙여 **질문과 주제가 같은 카드 안에서 연결**되어 보이게 했습니다.

### 검증 (헤드리스 렌더)
```
운영자 지정 → CH.3 우리 동네 AI        title="이번 주 주제: 우리 동네 AI (생활, 도움)"
자동 순환   → CH.2 멈춘 기계의 노래      title="이번 주 주제: 멈춘 기계의 노래 (고장, 원인 찾기)"
키워드 없음 → CH.5 AI 마을의 질문        title="이번 주 주제: AI 마을의 질문"
✅ growth/topic 이 없을 때 빈 문자열(예외 없음)
✅ XSS 방어: <img src=x onerror=...> → &lt;img ...&gt; 로 이스케이프
```
